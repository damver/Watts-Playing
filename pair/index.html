Inloggen zonder gedoe

Eén pagina om te bookmarken. Bij groen hoef je geen wachtwoord te typen op het autoscherm — je krijgt een code via e-mail/sms of een tik-bevestiging op je telefoon. Bij grijs moet je wachtwoord toch getypt worden; dat hoeft dan gelukkig maar één keer, de sessie blijft daarna staan.

✓Zonder wachtwoord — code via e-mail/sms

Open de link, en kies op de inlogpagina zelf de code-optie in plaats van het wachtwoordveld in te vullen.
